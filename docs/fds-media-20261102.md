# KUROSAKI FDS media diagnostics

The FC catalog now contains 76 rules, including:

| Event | Catalog ID | Meaning |
|---|---|---|
| `FDS_MEDIA_CRC_ERROR` | `FC_FDS_MEDIA_CRC_ERROR` | Drive observed a CRC mismatch; verify disk layout, side and controller/CRC sequencing |
| `FDS_MEDIA_WRITE_PROTECTED` | `FC_FDS_MEDIA_WRITE_PROTECTED` | Program requested disk writing while KUROSAKI media is read-only |

Both are warnings in `FDS/Media`. Ordinary FDS read/control/transfer trace
events are informational and are not converted into generic error floods.
The write warning does not imply that the source image changed. Retain the
original disk; changing SARAKURA cannot add persistent writes to the emulator.

Use the same pipeline as other FC diagnostics:

```powershell
kurosaki run game.fds --frames 1200 --emit-diagnostics events.jsonl
sarakura fc analyze --metadata game.nes.build.json --events events.jsonl --out report
```

Supply the matching build metadata and a user-provided FDS BIOS. BIOS bytes and
snapshots containing firmware must not be included in public reproduction
packages. The rules are tested with catalog-bound events and concrete guidance;
they do not certify physical disks or all nonstandard/protected image formats.
